## 📂 Proyectos destacados

### 🏪 Sistema de gestión para una tienda de barrio

Proyecto académico orientado a organizar las operaciones de una tienda física.

- Gestión de ventas e inventario.
- Organización de productos y proveedores.
- Consultas y manejo de información.
- Diseño de una solución para facilitar las operaciones del negocio.

**Tecnologías:** Python, JavaScript, HTML, CSS, MySQL y PostgreSQL, según la implementación de cada módulo.

### 🚗 Gestión de un concesionario de automóviles

Proyecto académico para practicar el diseño y la administración de bases de datos relacionales.

- Gestión de marcas, modelos, vehículos, clientes y ventas.
- Consultas SQL, JOIN y subconsultas.
- Funciones y procedimientos almacenados.
- Triggers y ejercicios de auditoría de precios.

**Tecnologías:** PostgreSQL, SQL y PL/pgSQL.
